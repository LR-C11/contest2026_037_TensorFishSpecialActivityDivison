# 定时会议误记为备忘修复（2026-11-07）

复现原话：30分钟之后有个会，帮我记一下。

原逻辑要求包含“提醒”“待办”等触发词才能建立相对时间待办，“记一下”会落到备忘解析。触发词位于句尾时又没有备忘正文，因而进入普通云端聊天。云端询问会议名后没有本地待办的待续状态，继续回答也无法创建提醒。

修复后，带有效相对时间的“记一下”请求优先创建待办；明确的未来会议陈述也可直接建立待办。泛称“有个会”使用“开会”作为标题，不再追问会议名称。普通无时间备忘、明确指定备忘目的地、疑问句、取消句和闹钟请求仍保留各自规则。

例句：
- 30分钟之后有个会，帮我记一下 → 待办“开会”，1800 秒后提醒。
- 帮我记一下30分钟后取快递 → 待办“取快递”，1800 秒后提醒。
- 30分钟之后有个产品评审会议，帮我记一下 → 待办“产品评审会议”。
- 帮我记一下买牛奶 → 备忘。

已通过 28 组宿主回归测试。新测试覆盖原话、汉字数字、前后置“记一下”、标题清理、备忘/问句/取消隔离，以及实际执行时只能调用待办保存接口、待办权限关闭后不能回退到备忘。
