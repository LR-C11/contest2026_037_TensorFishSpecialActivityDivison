# FlowDesk 逻辑修复记录

基于下载版本 b40db4f，直接修改当前目录中的源码。API 密钥按用户要求保留，隐藏的 BLE 配对模块已恢复到下载版本。本轮处理审查报告其余 23 项问题。

## 行为变化

- 语音分流要求明确的服药动作和药物上下文，支持已登记的自定义药名。单说“吃药”打开页面，普通聊天、游戏、计时、备忘和心情分别走对应分支。
- 否定和取消语句不会创建任务。已有任务的删除仍通过任务列表操作，设备会明确反馈。
- 服药语音必须说已登记的药名，不再把未知药名默认记到唯一药品上。打卡对应当前已经到达的计划时段，重复陈述不会继续消耗下一时段。补记通过页面手动确认。
- 服药主动提醒和打卡使用一致的日期编码。未校准或仅恢复旧时间种子的设备暂停按日期调度，避免误清已有记录。
- 待办、备忘先写临时文件，检查写入与关闭结果，再替换正式文件。手动新增、删除、打卡和心情保存失败时恢复原状态并提示。
- 所有到期提醒先进入队列，闹钟优先于普通待办。普通待办完成声音通知后约十秒自动让出弹窗，闹钟由用户确认关闭。存储失败仍显示提醒并重试保存。
- 录音等音频占用期间保留待办提示音的重试，用户确认或闹钟抢占后终止过期声音任务。主动提醒在播放完成后判断结果，失败时尝试备用提示音。
- 正在执行的指令会一直占有结果槽，完成后才允许复用。尚未开始执行的超时指令反馈设备忙，避免被当作普通聊天重新解释。
- 专注倒计时依据单调时钟实际经过时间，暂停时保留不足一秒的余量。
- 2048 统计改为每累计一分钟保存一次，退出页面时补存，减少写盘频率。
- Wi-Fi 状态命令失败或没有明确关联信息时不判为连接成功。连接检查与周期检查使用不同临时文件。
- 聊天和音色试听使用原子发布完成状态，确保主线程读到已写完的结果。
- 超过 31 字节的语音备忘明确拒绝并提示缩短，不再静默截断。列表满时优先复用已完成、未等待展示的提醒条目。
- 相对闹钟回复准确包含分钟和秒。

## 旧数据兼容

药品、备忘和心情的文件格式保持兼容。

提醒文件升级为带有 `#flowdesk-reminders-v2` 标头的格式，新增待展示状态。加载逻辑同时支持原先无标头的格式。新版保存后的提醒文件不适合直接交给旧版固件读取，回退固件前应备份设备上的提醒文件。

## 验证

`tests/test_regressions.py` 的 16 组宿主机 C 回归测试通过，覆盖语音分流、否定请求、药名与时段匹配、保存失败回滚、旧文件读取、提醒队列、音频占用重试、容量复用、实际时间计时、写盘频率、时钟校准和 Wi-Fi 状态异常。

另外，对 12 个修改后的 C 文件进行了宿主机语法检查。LVGL 与板级依赖使用接口桩，因此这些结果不能替代 Gemini-S1 SDK 的完整构建、链接和真机测试。

上板后应重点验证连续多轮语音、录音过程中提醒、两个提醒同时到期、跨日、离线重启和存储满。当前文件是源代码修复，开发板需要重新编译和烧录后才会运行这些修改。

API 密钥仍在源码中，公开仓库的凭据暴露风险仍存在。此次按照用户要求保留。
