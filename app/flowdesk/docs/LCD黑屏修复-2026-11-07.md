# FlowDesk LCD 黑屏修复（2026-11-07）

日志中 /dev/lcd0 打开成功，随后 FlowDesk 在 lv_display_set_buffers 中因 buf1 未对齐触发断言退出。
当前配置要求 LV_DRAW_BUF_ALIGN=64、LV_DRAW_BUF_STRIDE_ALIGN=16；原 LCD 适配层直接使用 lv_malloc，不能保证绘图缓冲区符合要求。

## 修改

SDK 文件：/home/lrc/vela/apps/graphics/lvgl/lvgl/src/drivers/nuttx/lv_nuttx_lcd.c

1. 使用 lv_draw_buf_create 和 lv_display_set_draw_buffers，让 LVGL 处理缓冲区对齐、步长和所有权。
2. 释放时使用 lv_draw_buf_destroy；首个或第二个缓冲分配失败时销毁显示对象，避免资源泄漏。
3. LCD 对齐信息查询失败时保留 1 像素默认值，避免使用全零对齐参数。
4. 保留硬件要求的 64 字节对齐和断言检查。

本目录保存补丁和修改后的 SDK 文件。应用补丁时在 apps/graphics/lvgl/lvgl 目录执行 git apply；本机 SDK 已完成修改，不需重复应用。
