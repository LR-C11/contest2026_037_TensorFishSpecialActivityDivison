# FlowDesk — Gemini-S1 桌搭伴侣（v0.19.0）

全新应用，**未复用**参赛仓 `desk_companion` 源码。

## 功能

### 专注
- **主页 = 专注设定**：15/25/45/60 + 自选
- **淡入倒计时页**、**滚轮倒计时** `MM:SS`
- **表情**：眨眼 / 注视 / 星星眼 / 爱心眼；点脸互动
- **完成页**：语音提示「专注完成」

### 语音聊天
- **点按录音**：点一下开始录，再点结束并发送
- 链路：`/dev/audio/pcm0c` → ASR `mimo-v2.5-asr` → LLM `mimo-v2.6-flash` → TTS `mimo-v2.5-tts` → 喇叭
- 云端：MiMo SGP OpenAI-compatible `https://token-plan-sgp.xiaomimimo.com/v1/chat/completions`；语音 ASR/聊天/TTS 和会议摘要也共用 SGP `/v1` 接口。
- ASR / LLM / TTS 都走 Chat Completions；冰糖、茉莉、苏打试听样本预置在 `/resource/audio/`，可离线试听；其他云端音色首用时在线生成并缓存到 `/data`。
- 本地语音意图：说“计时20分钟”或“专注20分钟01秒”启动对应时长；说“你好 openvela / hello openvela”显示问候并播放预置音色；说想玩小游戏先询问类型，再说 2048、猜数字或 24 点进入对应页；说“提醒我在20分钟之后开会”写入待办，到时弹窗、蜂鸣并尝试播报；说“明天早上7点叫我起床”设置语音闹钟；带日期/时刻的普通提醒保存为倒数日；说“记一下……”保存备忘；说“打开 MBTI”进入测试；说“我今天有点焦虑”会记录心情并给出支持性安慰；说“我刚吃了维生素”仅当该药已登记时记录服药。低落表达的回应保持倾听和非诊断，不把情绪记录文本发送给云端。

### 词典（BandLingo 风格）
- 本地词库约 6.5 万词（`word|definition`，a–z 分片，LRU 缓存）
- 英文查词 / 中文查释义 / 每日一词 / AI 释义
- **独立可滑动页面**：查词列表、释义详情

| 项 | 说明 |

| Wi-Fi | 可扫描并手动连接；如已有保存凭据，启动时会尝试连接 |
| 日期与时间 | 可手动校准；保存一个下次启动可用的本地时间种子 |

### 主动提醒（离线优先）
- 吃药 / 喝水 / 早间简报 / 专注完成 → 预置 WAV 提示音 + 屏幕文字
- Skill：`/resource/agent/skills/`（reminder、daily-briefing、focus-coach）

### 其它
- 功能页含备忘、词典、背单词、计算器、环境传感、猜数字、单位换算、喝水、待办、闹钟、倒数日、录音机、会议摘要、吃什么、24 点、画板、BMI、吃药、2048 和 MBTI。
- 「录音机」最多保存 10 段录音、每段最长 10 分钟，支持本地回放。
- 「会议摘要」每段最长 10 分钟；用户点“开始分析”后才上传音频进行 ASR、摘要与 TTS；音频、转写、摘要最多保留 3 份。
- **底栏**：专注 / 聊天 / 健康 / 功能 / 设定

## 使用指南与执行流程

### 通用操作与页面执行
- 底栏在专注、聊天、健康、功能、设定五个主页面间切换；功能列表可上下滚动，点一张卡进入对应页面，页面内按“返回”回到上一级。
- 页面在启动时由 `deskmate_main.c` 创建并注册到 `g_dm_pages[]`；按钮回调处理点按，`dm_show()` 显示目标页，`dm_tick()` 每 250 ms 分发时钟、提醒、页面状态更新。
- 录音、播放、网络请求等较慢任务由工作线程执行，完成状态再由 UI tick 更新屏幕，避免在触摸回调中长时间等待。
- 写明了 `/data` 路径的用户记录通常在重启后保留；`/tmp` 中的录音转换文件、请求/响应文件只是临时工作文件。

### 专注
1. 底栏点「专注」，选择 15 / 25 / 45 / 60 分钟，或选择自选后用 `+/-` 调整时长，再点开始。
2. 运行页显示倒计时，可暂停/继续或提前结束；时间归零后显示完成页并播放完成提示。
3. 执行逻辑：专注状态由应用计时器逐秒更新；完成后写入健康页的当日专注分钟数。

### 聊天与语音助手
1. 在「聊天」点录音按钮开始，再点一次停止并发送；录音最长 6 秒，超时会自动结束。点页面表情触发固定的文字聊天请求；没有通用自由输入键盘。
2. 语音处理顺序：录音 → MiMo ASR 转写 → 本地意图匹配 → 未匹配时请求 MiMo 聊天模型 → TTS 播报。网络或云端失败时显示本地回复/错误，不保证一定有语音输出。
3. 本地优先处理专注计时、MBTI、已登记药品服用打卡、心情记录、备忘、待办、闹钟及小游戏等意图；命中后不需要把该操作交给聊天模型执行。
4. 心情示例：“我最近心情不太好”“我有点焦虑”。助手会先表达理解、邀请用户继续说，再给简单的呼吸/休息建议；匹配到具体心情时同步保存健康记录。它不是诊断或治疗工具。
5. 用药示例：“我刚吃了维生素”。只有语句明确表示已经服用、且药名能匹配药品清单时才打卡；问题、否认、提醒及不明确药名不会打卡。MBTI 示例：“打开 MBTI”。
6. 云端路径：文字聊天/词典 AI 释义走 `dm_chat_ai.c`；语音 ASR/聊天/会议摘要/TTS 走 `dm_voice.c`。这些调用共用 MiMo SGP `/v1` 基址，但按任务使用不同模型/接口。`/data/deskmate_mimo.key` 若存在且有效，会覆盖固件里的备用凭据；文档不写入凭据内容。

### 健康与心情
1. 底栏点「健康」查看心情分、当日专注、喝水及最近记录。
2. 点「记录心情」，切换“当前/今日整体”，选择一个或多个心情标签，可再点快捷心情描述，最后点保存。
3. 语音自述中检测到明确的第一人称心情词时，会自动保存一条当日记录并给出回应；说“记录心情”但没描述情绪时会打开手动选择页。记录保存在 `/data/deskmate_mood.bin`，每日统计会在日期变化后重置。
4. 综合分由当前实现的心情、专注、喝水及其他可用日常数据按规则计算；数据不足时显示已有维度，不应视作医学结论。

### 设定页面
- **Wi-Fi**：打开开关或进入 Wi-Fi 页扫描热点，选网络并连接；加密网络需在板端键盘输入密码。保存凭据后可供应用网络请求使用。连接和认证失败会显示状态，不保证所有接入点兼容。
- **日期与时间**：用步进器调整本地年月日时分，应用后立即设置设备时钟并保存下次启动的临时种子；NTP 有效后可校正。有效系统时间也影响 HTTPS/TLS 验证。
- **音量**：调媒体音量、静音/试听和独立闹钟音量。闹钟响铃暂时使用单独的响铃音量，并在停止后恢复媒体状态。
- **播报声音**：选音色并试听。少数预置音色可离线试听；其他音色可能需要网络合成并缓存。
- **关于**：查看版本号与开发者资料。App BLE 设置入口当前隐藏，不代表 BLE 相关代码已从固件移除。

### 应用执行主流程
1. `deskmate_main.c` 创建主页和功能页、初始化音色/设置、显示专注主页，并注册周期定时器。
2. LVGL 页面按钮的事件回调负责收集用户动作；`dm_show()` 执行页面切换。定时逻辑由 `dm_tick()` 按 `DM_TICK_MS` 运行，检查页面状态、倒计时、提醒和后台任务结果。
3. `dm_assistant.c` 先做本地关键词/时间意图匹配：本地闹钟、待办、专注、心情、服药、MBTI、备忘、小游戏等命中后直接调用对应模块；未命中语音指令才进入云端聊天回复。
4. `dm_chat_ai.c` 负责文字聊天和词典 AI 释义；`dm_voice.c` 负责语音 ASR、语音 LLM、会议分析和 TTS。长请求与音频处理在 worker 线程执行；音频/HTTP 的中间文件在 `/tmp`，不可当作持久记录。
5. 本地功能即使没有网络也可用；ASR/云端聊天/AI 词典/在线 TTS/会议分析需要 Wi-Fi、有效 TLS 时间及服务可达。网络服务失败时只显示错误或本地回退，不代表云端功能已完成。

## 设备运行时配置

- 默认使用固件内置的 Token Plan API 密钥；如 `/data/deskmate_mimo.key` 存在且有效，则优先使用该运行时密钥覆盖。源码和固件会包含默认密钥，请勿公开分发；已暴露密钥建议轮换。
- HTTPS 优先依赖 NTP 有效样本；设置页可手动设定设备本地日期时间，并保存上次设定作为下次启动的临时时钟种子，NTP 有效后再自动校正。TLS 证书校验保持开启。
- 冰糖、茉莉、苏打预置 WAV 打包在 `/resource/audio/`，可离线试听；其他音色首次试听需要云端合成并缓存到 `/data`。
